# История Infinity Xray

## 0.3.2 — 2026-11-17

- Образ собирается на `remnawave/node:3.4.6` (было 3.4.5). Xray-core тот же — v26.11.9, в 3.4.6 официальный образ поставляется с ним же; патч не менялся.

## 0.3.1 — 2026-11-17

- REALITY принимает ClientHello только с ключом X25519, без X25519MLKEM768. Upstream с конца октября 2026 отбрасывает такие ClientHello как устаревшие, а mihomo 1.19.34 (Clash Verge, FlClash, XKeen на Keenetic) MLKEM не отправляет: клиент видит `REALITY Authentication: false`, сервер отдаёт сертификат сайта-маскировки. Повторный ключ одной группы по-прежнему отклоняется.
- Модуль `github.com/xtls/reality` перенесён в `third_party/reality` и подключён через `replace`; остальное без изменений.
- Проверено на рабочей ноде: mihomo 1.19.34 — TCP Reality и gRPC Reality проходят (117–144 мс), Xray 26.11.9 как клиент — HTTP 204.

## 0.3.0 — 2026-11-17

- Уровни скорости на email, в дополнение к общему лимиту `XRAY_IC_USER_RATE_*`:
  - «бесплатные» — свой лимит `XRAY_IC_FREE_RATE_MBPS` (в обе стороны) для email из файла `XRAY_IC_FREE_USERS_FILE`;
  - «без лимита» — email из файла `XRAY_IC_UNLIMITED_USERS_FILE` не ограничиваются по скорости; список важнее списка бесплатных.
- Файлы: по email на строку, `#` — комментарий. Перечитываются каждые 5 с при смене времени изменения или размера; пропавший или битый файл сохраняет прежний список. В лог пишется число записей (`[icusers] free users: N`, `[icusers] unlimited users: N`).
- Уровень входит в ключ ведра: после переноса email между списками новые соединения сразу получают новый лимит, открытые остаются на старом до переподключения.
- Проверено на рабочей ноде за CDN (XHTTP): «бесплатные» при 5 Мбит/с — 4,8–4,9 Мбит/с, обычные при 13 Мбит/с — 12,4–12,6, «без лимита» — 24 Мбит/с в один поток и 72 в три; после удаления из списка — снова 12,5. Лимит общий на email: несколько потоков его не превышают.

## 0.2.0 — 2026-11-11

- Стабильный выпуск на коде 0.2.0-rc.3: Xray-core v26.11.9, образ на `remnawave/node:3.4.5`.
- Проверено на рабочей ноде за L4-реле (XHTTP + REALITY, Hysteria2): 0 рестартов, около 32% одного ядра при ~130 Мбит/с, governor срабатывает, метрики и icstats работают. Отчёт: `reports/0.2.0-rc.3-node-report.md`.
- A/B-сравнения с 0.1.0 на одной ноде нет. `XRAY_XHTTP_FLOW_COMPETE` остаётся экспериментальным.

## 0.2.0-rc.3 — 2026-11-09

- Патч перенесён на Xray-core v26.11.9. В `common/mux/server.go` запись mux объединена с новым `MutexWriter` upstream; учёт активности и keepalive сохранены.
- Поведение сборки не менялось. Сравнение на реальном канале для этой версии ещё не проводилось.
- База образа — `remnawave/node:3.4.5` (в ней тот же Xray-core v26.11.9 и исправление `script` в routing). Дефект синхронизации последнего пользователя Node 3.4.4 в списке изменений 3.4.5 не упомянут, считать неисправленным.

## 0.2.0-rc.2 — 2026-11-09

- Режим конкуренции: дополнительное уменьшение окна больше не отменяет рост при распознанной чужой очереди. Собственная очередь и соседние закачки сохраняют защиту.
- TLS: горячая замена сертификатов и OCSP публикует неизменяемые снимки; неполная замена пары файлов сохраняет последний рабочий сертификат. Выдача сертификатов CA больше не меняет общий `tls.Config` во время handshake.
- Устранена гонка синхронизации в QUIC-тесте upstream. Проверки сборки включают TLS.
- Добавлены регрессионные тесты полного цикла controller, замены сертификатов и параллельной выдачи CA. Экспериментальный режим конкуренции остаётся выключенным по умолчанию.

## 0.2.0-rc.1 — 2026-11-08

- Отзыв VLESS-пользователей с отсрочкой; смена ключа закрывает старые соединения сразу.
- Лимиты на пользователя: число соединений VLESS и общая скорость.
- Экспорт счётчиков в формате Prometheus, новые счётчики governor, inbound и лимитов.
- Плавная остановка и предел времени запуска.
- Экспериментальный режим конкуренции governor для единственной закачки с адреса: при 100 Мбит/с на стенде поднимает полосу рядом с TCP примерно втрое, при 20 Мбит/с срабатывает не всегда, задержку не улучшает.

Новые возможности выключены по умолчанию, кроме предела запуска 60 секунд.

## 0.1.0-rc.1 — 2026-11-08

Первый именованный кандидат релиза. Это новая система выпуска существующих
серверных патчей, а не новая версия официального Xray.

- Единый патч: keepalive Hysteria/mux, mux поверх XHTTP, проверка REALITY,
  TCP-only Mux.Cool, серверный governor HTTP/2, ограниченная остановка,
  диагностика записей mux.
- Фиксированная база Xray v26.10.31 и Go 1.27.3, сборка с `http2legacy`.
- Версия Infinity Xray в выводе `xray version`, отдельные каталоги артефактов,
  `build-info.json`, SHA256 бинарника, версионируемый тег Docker.
- Один сценарий сборки для Linux и Windows; старые рабочие каталоги сохраняются.
- Экспорт отдельного репозитория по явному списку публичных файлов.
- Патч принудительного отзыва пользователей исключён: несовместим с remove/add
  при обычной синхронизации Remnawave Node 3.4.4.

Статус RC сохраняется до полного Linux-прогона и проверки итогового Docker-образа.
Исторические тесты отдельных компонентов не заменяют проверку объединённого релиза.
