# История Infinity Xray

## 0.2.0-rc.2 — 2026-11-09

- Режим конкуренции: дополнительное уменьшение окна больше не отменяет рост при распознанной чужой очереди. Собственная очередь и соседние закачки сохраняют защиту.
- TLS: горячая замена сертификатов и OCSP публикует неизменяемые снимки; неполная замена пары файлов сохраняет последний рабочий сертификат. Выдача сертификатов CA больше не меняет общий `tls.Config` во время handshake.
- Устранена гонка синхронизации в QUIC-тесте upstream. Проверки сборки включают TLS.
- Добавлены регрессионные тесты полного цикла controller, замены сертификатов и параллельной выдачи CA. Экспериментальный режим конкуренции остаётся выключенным по умолчанию.

## 0.2.0-rc.1 — 2026-11-08

- Отзыв VLESS-пользователей с отсрочкой; смена ключа закрывает старые соединения сразу.
- Лимиты на пользователя: число соединений VLESS и общая скорость.
- Экспорт счётчиков в формате Prometheus, новые счётчики governor, inbound и лимитов.
- Плавная остановка и предел времени запуска.
- Экспериментальный режим конкуренции governor для единственной закачки с адреса: при 100 Мбит/с на стенде поднимает полосу рядом с TCP примерно втрое, при 20 Мбит/с срабатывает не всегда, задержку не улучшает.

Новые возможности выключены по умолчанию, кроме предела запуска 60 секунд.

## 0.1.0-rc.1 — 2026-11-08

Первый именованный кандидат релиза. Это новая система выпуска существующих
серверных патчей, а не новая версия официального Xray.

- Единый патч: keepalive Hysteria/mux, mux поверх XHTTP, проверка REALITY,
  TCP-only Mux.Cool, серверный governor HTTP/2, ограниченная остановка,
  диагностика записей mux.
- Фиксированная база Xray v26.10.31 и Go 1.27.3, сборка с `http2legacy`.
- Версия Infinity Xray в выводе `xray version`, отдельные каталоги артефактов,
  `build-info.json`, SHA256 бинарника, версионируемый тег Docker.
- Один сценарий сборки для Linux и Windows; старые рабочие каталоги сохраняются.
- Экспорт отдельного репозитория по явному списку публичных файлов.
- Патч принудительного отзыва пользователей исключён: несовместим с remove/add
  при обычной синхронизации Remnawave Node 3.4.4.

Статус RC сохраняется до полного Linux-прогона и проверки итогового Docker-образа.
Исторические тесты отдельных компонентов не заменяют проверку объединённого релиза.
