# История Infinity Xray

## 0.1.0-rc.1 — 2026-11-08

Первый именованный кандидат релиза. Это новая система выпуска существующих
серверных патчей, а не новая версия официального Xray.

- Единый патч: keepalive Hysteria/mux, mux поверх XHTTP, проверка REALITY,
  TCP-only Mux.Cool, серверный governor HTTP/2, ограниченная остановка,
  диагностика записей mux.
- Фиксированная база Xray v26.10.31 и Go 1.27.3, сборка с `http2legacy`.
- Версия Infinity Xray в выводе `xray version`, отдельные каталоги артефактов,
  `build-info.json`, SHA256 бинарника, версионируемый тег Docker.
- Один сценарий сборки для Linux и Windows; старые рабочие каталоги сохраняются.
- Экспорт отдельного репозитория по явному списку публичных файлов.
- Патч принудительного отзыва пользователей исключён: несовместим с remove/add
  при обычной синхронизации Remnawave Node 3.4.4.

Статус RC сохраняется до полного Linux-прогона и проверки итогового Docker-образа.
Исторические тесты отдельных компонентов не заменяют проверку объединённого релиза.
